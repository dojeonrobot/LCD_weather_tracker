# 예제 CSV 만든 방법

수업용 날씨 CSV입니다. 값은 **실제 기상 자료**에서 가져왔고, 사람이 임의로 채워 넣은
숫자는 없습니다.

## 출처

| 항목 | 내용 |
| --- | --- |
| 자료 | Open-Meteo Historical Forecast API (고해상도 수치예보 아카이브) |
| 기간 | 금천구 2026-01-01 ~ 08-31 · 광명시 2026-01-15 ~ 08-31 |
| 조회 단위 | 행정동 중심 좌표별로 각각 조회 (동마다 값이 다릅니다) |
| 결측 | 0건 |

## 각 열의 의미

| 열 | 설명 |
| --- | --- |
| 일시 / 날짜 / 시간 | 관측 시각. **매 관측일 오후 2시** 고정 |
| 기온 · 습도 · 풍속 · 체감온도 | 그 시각의 값 |
| **일강수량(mm)** | 그날 00시~24시 **합계**. 특정 시각의 강수량이 아닙니다 |
| 날씨상태 | 그날의 대표 날씨코드(WMO)를 한글로 옮긴 값. 기온이 33°C 이상이면 `폭염`, 최저 -12°C 이하면 `한파` |
| 뉴스/주의 | 위 값들에 기상청 특보 기준을 적용한 결과 (일강수량 110mm↑ `호우경보`, 60mm↑ `호우주의`, 체감최고 35°C↑ `폭염경보` 등) |

체감온도는 실측값이라 **여름에는 기온보다 높고**(습도 반영) **겨울에는 낮습니다**(바람 반영).

## 알아둘 점

- **행정동별 관측소는 실제로 존재하지 않습니다.** 기상청에도 동 단위 관측소는 없습니다.
  여기서는 동 중심 좌표(근사값)로 각각 조회했고, 수치예보 격자가 지형·고도를 반영하기 때문에
  동마다 값이 조금씩 다릅니다. 같은 격자에 드는 이웃 동끼리는 값이 거의 같을 수 있습니다.
- 겨울(1~2월)은 실제로 비·눈 온 날이 적어 **일강수량이 0인 행이 몰려 있습니다.**
  강수량 그래프를 볼 때는 시작 행을 6월 이후로 옮기면 장마 구간을 볼 수 있습니다.
- 재생성 스크립트는 저장소에 포함하지 않았습니다. 다시 만들 때는 위 출처와 규칙을 그대로 쓰면 됩니다.
